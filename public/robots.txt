# ARTIT.hu — robots.txt (Task 017; EN routes confirmed Task 018)
#
# Production HU and EN pages are indexable by default; every production
# route already carries no <meta name="robots"> tag (see BaseLayout.astro),
# so no Allow rules are needed for them — this applies unchanged to the
# `/en/*` routes added in Task 018, since the Disallow rules below are
# path-prefix rules that never matched anything under `/en/` in the first
# place (no art-direction/design-foundation route has an EN counterpart —
# see DOC/03's Task 018 route map). The only routes intentionally excluded
# from crawling are internal art-direction/dev-only routes — each of those
# already carries <meta name="robots" content="noindex"> individually (see
# ExperimentalBanner-using pages under src/pages/art-direction/ and
# src/pages/design-foundation.astro); the Disallow rules below are a second,
# independent layer (a crawler that ignores robots meta still won't be
# directed to spend budget here), not a replacement for the per-page noindex
# tag — see DOC/13-CONTENT-GAPS-AND-VALIDATION.md's "Task 017" note.
#
# Sitemap (Task 019) — `@astrojs/sitemap`, the standard Astro-supported
# integration (see `astro.config.mjs`), generated at build time from the
# now-wired `site: 'https://artit.hu'`. Its own `filter` option excludes the
# same internal routes the Disallow rules below target, kept as one
# consistent list rather than two independently-maintained ones — see that
# config's own comment.

Disallow: /design-foundation/
