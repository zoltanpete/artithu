## 5. Finomítások

### 5.1 Hero tipográfiai ritmus

A jelenlegi A4.3.1 H1 mérete már közelebb van a kívánthoz. Ne növeld vissza.

Finoman ellenőrizd a vertikális ritmust: eyebrow → H1 → lead → CTA row.

A H1, lead és CTA között legyen **árnyalatnyival több levegő**, mint egy standard kompakt marketing Hero-ban, de ne essen szét a blokk. A cél: editorial confidence, nem oversized SaaS headline.

### 5.2 Bemeneti node-ok vertikális ritmusa

- Legyenek jól elkülönülő, rendezett források.
- Ne legyenek zsúfoltak, de ne is essen szét a stack.
- A halk `…ÉS MINDEN MÁS FORRÁS` maradjon másodlagos.
- A stack és a FOLYAMAT között legyen elég vízszintes tér az íves útvonalaknak.

### 5.3 Ikonok — beszédesebb, egységesebb rendszer

Készíts egységes, finom line-icon családot inline SVG-ből, külső dependency nélkül:

- `EXCEL` → grid/cell ikon, visszafogott zöld cella-accenttel;
- `E-MAIL` → boríték;
- `KÜLÖN RENDSZER` → két összekapcsolt láncszem / linked system;
- `KÉZI ADAT` → pointer vagy kézi bevitel jel;
- `API` → code brackets / endpoint;
- `…ÉS MINDEN MÁS FORRÁS` → három pont / generic source;
- `JÓVÁHAGYÁS` → körben check;
- `SZÁMLÁZÁS` → dokumentum/invoice.

Az ikonok legyenek optikailag azonos súlyúak, egyszerűek, nem emoji-szerűek, és illeszkedjenek a Swiss systems / engineering editorial karakterhez.

### 5.4 Node konténerek finomítása

Tartsd meg a finoman lekerekített node-dobozokat, de ezek **diagram object / system component** elemek legyenek, ne generic cardok.

Finomítsd a border kontrasztot, belső paddinget, ikon–label ritmust, port–container kapcsolatot és selected/hover állapotot. A selected state maradjon kontrollált.

### 5.5 Portok / csatlakozási pontok

Minden node és útvonal találkozásánál legyen egyértelmű kis outlined-circle port, pontosan a görbe végpontján. Static állapotban finom, focus/selected állapotban enyhén erősödhet/nőhet.

Külön mérd le, hogy a button overlay középpontja és a vizuális node középpontja minden interaktív node-nál helyes-e.

### 5.6 Görbék és nyílhegyek

- Minden releváns útvonal legyen finoman ívelt.
- Kerüld a merev connector-hatást.
- A nyílhegy legyen kicsi és precíz.
- A három route hierarchy statikusan is olvasható legyen.

**Primer:** blue-violet, enyhén vastagabb.  
**Szekunder:** neutral, vékonyabb, halkabb.  
**Kivétel / alternatív:** dashed, nagyon halvány, de felismerhető.

### 5.7 FOLYAMAT core arány és belső komponens

A `FOLYAMAT` legyen a diagram legerősebb objektuma.

Külső shell: szélesebb/alacsonyabb, finom neutral surface, ne legyen „hasas” vagy dashboard-card.

Belső lila core: elnyújtott, széles és alacsony; `FOLYAMAT ⊙` felirat; az `⊙` a szó **után** legyen, optikailag egy sorban. A lila core maradjon a legerősebb tömör accent objektum.

### 5.8 Koncentrikus gyűrűk

Tartsd meg és finomítsd a FOLYAMAT körüli koncentrikus köröket:

- több nagyon alacsony opacity-jű blue-violet tonal layer;
- néhány fill-ring + 1–2 stroked ring;
- pontos középpont;
- ne glow-filteres/neonos hatás legyen;
- inkább „field / transformation zone”;
- interakciókor nagyon finoman erősödhetnek.

### 5.9 Output node-ok

`JÓVÁHAGYÁS` és `SZÁMLÁZÁS` ugyanabba a diagramnyelvbe tartozzon, de olvasódjanak resolved outputként.

- beszédes ikon;
- rendezett label;
- port;
- semantic-green status dot;
- a státuszpont legyen frissebb/brighter, közelebb a referencia neon-green karakteréhez, de ne váljon brand-accentté.

### 5.10 Construction guides / koordináták

Adj vissza / finomíts:

- nagyon halvány horizontális guide;
- nagyon halvány vertikális guide;
- origin/crosshair a process környezetében;
- 1–2 nagyon halk koordináta-jelölés, pl. `X / 01`, `Y / 01`, `X / 02`, `Y / 02`;
- esetleg apró registration tick-ek.

Cél: blueprint residue / construction logic. **Ne** hozd vissza a korábbi nagy `SEC / 01` vagy `01────────02` ruler megoldást.

### 5.11 Legend — elhelyezés és ritmus

A jelenlegi legend tartalmilag jó, de az elhelyezése nem elég rendezett.

**Választott irány: a diagram alatt, középre rendezett legend.**

- Ne csússzon be a bal oldali Hero-copy alá.
- Kizárólag a diagram vizuális területéhez tartozzon.
- Legyen a diagram középvonalához igazítva.
- Legyen **érzékelhetően nagyobb vertikális távolság** a diagram és a legend között.
- Desktopon maradjon egy sorban:
  - `PRIMER ÚTVONAL`
  - `SZEKUNDER ÚTVONAL`
  - `KIVÉTEL / ALTERNATÍV`
- Mindegyikhez valós stroke-swatch tartozzon.

A legend alatt legyen külön signature blokk:

`BEMENETEK → FOLYAMAT → KIMENETEK`

alatta:

`TISZTA. KAPCSOLÓDÓ. ÁTLÁTHATÓ.`

A legend és a signature között legyen tiszta spacing. Ne olvadjanak sűrű metadata-sorrá. A teljes annotation zone legyen kisebb vizuális súlyú, mint maga a graph.

### 5.12 Hero-kompozíció integráció

A graph ne érződjön külön jobb oldali widgetnek.

Finoman ellenőrizd, hogy az input stack közelebb nyúlhat-e a két oszlop közti térhez, és egy-egy halk guide-line optikailag átnyúlhat-e a Hero két zónája között, a H1/lead olvashatóságának sérülése nélkül.

Ne legyen tényleges overlap a szöveggel.

### 5.13 Mikro-optikai finomhangolás

Külön visual-review passban ellenőrizd:

- görbék tangentjeit a portoknál;
- arrowhead-ek pozícióját;
- portok középpontját;
- ikonok és label-ek baseline-ját;
- outputok ritmusát;
- core és rings középpontját;
- legend valódi optikai középre igazítását;
- guide-line ütközéseket;
- H1 és graph vizuális súlyának egyensúlyát;
- accidental clippinget akkor is, ha nincs scrollbar.

Itt már **a részleteken múlik az összhatás**.

## 6. Interakció

Az A4.3.1 interakciós modelljét tartsd meg és ne egyszerűsítsd vissza.

Minden interaktív node reagáljon hover, keyboard focus, click/Enter, commit, deselect és switch állapotokra.

A state változásban kombinálható: path stroke-width/opacity, port emphasis, node border emphasis, nagyon enyhe node translation a core felé, core/ring subtle emphasis.

Ne használj nagy ugrást, forgást, spring/bounce animációt. `prefers-reduced-motion: reduce` esetén a mozgás gyakorlatilag tűnjön el.

## 7. Mobil

A mobil továbbra is külön kompozíció legyen.

- Nem kell a desktop összes dekoratív koordinátáját megtartani.
- Kevesebb input maradhat az A4.3.1 logikája szerint.
- Az ikon/node/core/port/arrow grammar maradjon.
- Legend egyszerűsödhet vagy törhet több sorba.
- Construction guides redukálhatók.
- Interakció maradjon használható.
- Ne legyen szövegütközés vagy horizontal overflow.
- Ne csak desktop SVG legyen lekicsinyítve.

---

## 8. Accessibility

Kötelező:

- valódi `<button>` interaktív overlay;
- helyes `aria-label`;
- helyes `aria-pressed`;
- keyboard reachability;
- látható `:focus-visible`;
- Enter aktiválás;
- state ne csak színnel kommunikáljon;
- SVG megfelelő `role="img"` + leíró `aria-label`;
- reduced-motion valóban működjön.

A focus outline geometriailag pontosan vegye körül a node-ot.
